## Description
- This project is a simple Personal Blog that runs in the local browser. It allows users to create, view, edit, and delete blog posts. The posts are stored in local storage so they remain available after refreshing the page.

## Reflection
- Building this project helped me practice HTML, CSS, JavaScript, DOM manipulation, form validation, and local storage. One challenge I faced was handling the edit and delete features. I used a unique ID for each post to find and update or delete the correct post. I also used an editingPostId variable to know when I was editing an existing post instead of creating a new one.
